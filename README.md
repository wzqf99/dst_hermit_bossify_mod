# 寄居蟹隐士 Boss

将帝王蟹的信物交给寄居蟹隐士，向她发起挑战。

## 简介

本模组为寄居蟹隐士（Hermit Crab）添加了一场 Boss 战。玩家进入游戏后会自动获得**帝王蟹的信物**（漂流瓶外观），将信物交给寄居蟹隐士即可触发战斗。

## 玩法

1. 进入游戏后，背包内会自动获得信物
2. 找到寄居蟹隐士，将信物交给她
3. 寄居蟹隐士进入战斗状态（1500 血量、40 点攻击力）
4. 击败她后会掉落珍珠，并解锁新的可制作物品

**注意**：如果所有玩家远离战场超过 10 秒，Boss 战会自动结束。

## 安装
- (根据盘符)手动下载放入 D:\steam\steamapps\common\Don't Starve Together\mods 目录

## 注意事项

- 需要**所有玩家**启用此模组
- 仅兼容 Don't Starve Together（单机版不支持）
- 需要 API 版本 10 或更高
