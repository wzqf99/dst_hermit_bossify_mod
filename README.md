# 寄居蟹隐士 Boss

将帝王蟹的信物交给寄居蟹隐士，向她发起挑战。

## 简介

本模组为寄居蟹隐士（Hermit Crab）添加了一场 Boss 战。每名玩家首次进入该存档时会获得一次**帝王蟹的信物**（漂流瓶外观），将信物交给寄居蟹隐士即可触发战斗。信物在战斗成功触发后会立即返还，不会被消耗。

## 玩法

1. 首次进入该存档时获得信物；游戏会优先将其放入物品栏，无法收纳时会落在玩家附近
2. 找到寄居蟹隐士，将信物交给她
3. 原寄居蟹隐士暂时退场，原地生成战斗形态（1500 血量、40 点攻击力）
4. 击败战斗形态后会掉落珍珠，并在寄居蟹商店解锁珍珠冬季盛宴饰品兑换项

**注意**：如果所有玩家远离战场超过 10 秒，Boss 战会自动结束。

## 安装
- (根据盘符)手动下载放入 D:\steam\steamapps\common\Don't Starve Together\mods 目录

## 注意事项

- 需要**所有玩家**启用此模组
- 仅兼容 Don't Starve Together（单机版不支持）
- 需要 API 版本 10 或更高
