## 帝王蟹胜利演出 —— 重写（第 2 版）

前两版都失败并被用户回退了。这次是结合原版源码分析后重写。

### 关键结论：动画必须走 StateGraph

DST 中 `AnimState:PlayAnimation` **只在本地生效，不会复制到客户端**。
纯 prefab 里直接调用，结果就是只有服务端"看到"演出、其他玩家屏幕静止。
原版帝王蟹的 reappear/disappear 同样由 `SGcrabking` 驱动。
→ 必须有独立 SG，用 `GoToState` 触发动画，动画放 onenter（客户端也执行）。

参考实现：`dst_origin_script/stategraphs/SGcrabking.lua` 的
`inert` / `reappear` / `disappear` 三态；`go_to_inert` 在 animover 里跳转。

### 关键结论：hermitcrab_marker 在陆地，不是海面

`hermitcrab_marker` 由 `hermitcrab_relocation_manager` 放在岛屿**几何中心**，
原文注释 "Place at island center, achievement marker for island center point"。
所以不能拿它当演出点。

岛屿实际几何（从 `map/static_layouts/hermitcrab_01.lua` 20x20 解出）：
- 陆地块 gid 17=MUD / 18=BRICK / 41=QUAGMIRE_CITYSTONE / 34=LAVAARENA_TRIM
- 41 与 34 是太极的两半，17/18 是外围过渡
- 布局外(0) 由世界生成器填成海洋
- 陆地块整体近似**正方形**（不是八边形），坐标来自 monkeyisland_01（36x36）

→ 演出点做法：以 marker 为起点，沿固定方向向外推进找第一个
`IsOceanAtPoint(x, 0, z, false)` 为真的点。

### 方向/坐标约定（易错）

原版 `brains/pollyrogerbrain.lua::FindNearbyOceanPos` 是权威：
```
xoff = r * math.cos(theta)
zoff = r * math.sin(theta)
```
**不做取负**。DST 世界坐标 +x 向右、+z 向上（屏幕）。
所以 -PI/2 = 朝南。我第一版误加了负号，已修正。

`Map:IsOceanAtPoint` 签名是 `(x, y, z, allow_boats)`，中间是高度传 0。

### 台词表两种写法别混用

- 隐士 Boss 血线台词：**字符串键**（"90"/"70"/…），配 `Chatter(表名.."."..key, 索引)`
- 本次演出台词：**数组 + 数值索引**，配 `Chatter(表名, 数值索引)`

原因：`npc_talker:Chatter` 内部 `strtbl:split(".")` 逐层查表，
服务端校验和客户端解析都依赖这个字符串路径。

## 经验：Lua 语法检查方法

DST 缺 Lua 语法错误时是静默失败，排查成本极高。
可用 `lupa` 在 Python 里做真实语法检查：
```
pip install lupa
L = lupa.LuaRuntime()
load = L.eval('function(src,name) local f,e=load(src,name); return f~=nil, e or "" end')
```
装在 `~/.workbuddy-ai/binaries/python/envs/default`。

## 经验：prefab 构造顺序

正确顺序（对照 `scripts/prefabs/hermitcrab_boss.lua`）：
`AddTransform/AddAnimState/AddSoundEmitter/AddNetwork` →
外观设置 → AddTag → AddComponent（pristine 阶段也要跑的）→
`SetPristine()` → `ismastersim` 早退 → 服务端专属（SetStateGraph 等）。

`AddNetwork()` 必须在 AddComponent 之前，我第一版顺序错了，已修正。
